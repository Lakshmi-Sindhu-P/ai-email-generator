## Project Goal

Build a smart email assistant that:
- Accepts structured user input (recipient, context, tone, purpose, key info)
- Generates multiple personalized email drafts and subject lines using AI
- Handles incomplete or noisy input gracefully
- Offers extensibility for domain-specific generation (e.g., insurance emails)

---

## Features

- Two email drafts per prompt: Formal and Friendly tone
- Subject line generation with multiple options
- Input form validation and error handling
- JSON output for easy downstream use
